# Responsible use

GratitudeOps is a local logging tool. It is not a security product. It does not encrypt your data by default.

## Keep data private

Do not store highly sensitive information.
Avoid storing addresses, government IDs, private medical details, or anything that could harm someone if exposed.

Do not upload your database file to GitHub.
Do not share your database file publicly.

## Do not use for harm

Do not use this tool to stalk, harass, dox, intimidate, or track people in ways that put them at risk.

This project is meant to support gratitude, accountability, and reciprocity, not surveillance.

## You control how you use it

You are responsible for your data and how you use the tool.
If you are using GratitudeOps in a workplace or program, follow your organization’s policies.
